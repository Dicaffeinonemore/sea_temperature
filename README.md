# sea_temperature

## HTML 버전

`app.html`을 더블클릭해 브라우저에서 열면 됩니다. Python이나 서버가 필요하지 않으며, 아래 파일들이 같은 폴더에 있어야 합니다. 화면(기능)별로 파일이 나뉘어 있어 담당자가 자기 화면만 데이터에 연결할 수 있습니다.

| 파일 | 화면 | 데이터 연결 (짝) |
|---|---|---|
| `app.html` | 시작 · 양식장 등록 · 로그인 · 회원가입 | – |
| `home.html` | 홈(오늘의 수온): 현재 상황 · 예측 추이 · 특보 | 앱-2 ↔ n8n-3 (`{"region": ...}`) |
| `insurance.html` | 보험 정보 비교 · 지원제도 | 앱-1 ↔ n8n-1 (`{"species": ...}`) |
| `response.html` | 대응 요령 | 위험 단계·특보 데이터 |
| `start_bg.jpg` | 시작 화면 배경 사진 | – |

- 시작 → 양식장 등록 → 홈(오늘의 수온)으로 이동하고, 하단 탭바와 ☰ 사이드 메뉴로 대응 요령·보험 정보를 오갑니다. 홈 좌측 상단의 로그인 → 회원가입으로 가입 화면에 진입합니다.
- 지역 목록과 수온·보험·대응 정보는 내장된 예시이며 API에 연결하지 않습니다.
- 양식장 정보(지역·품종·방식·보험)는 브라우저 탭의 sessionStorage(`farm` 키)에 저장되어 모든 화면에서 읽을 수 있고, 탭을 닫거나 로그아웃하면 지워집니다. 홈에 들어왔는데 양식장 정보가 없으면 양식장 등록으로 이동합니다. 이름·생년월일·전화번호는 페이지 메모리에만 두며, 실제 계정은 생성하지 않고 비밀번호는 가입 완료 또는 화면 이동 시 지웁니다.
- 다른 화면에서 `app.html#register`(조건 수정), `app.html#login`(로그인)으로 들어오면 해당 화면이 바로 열립니다.
- HTML 버전은 Streamlit 버전과 별개입니다. `app.py` 수정이 자동 반영되지는 않습니다. HTML의 `<style>`은 디자인, `<section>`은 화면 항목, `<script>`는 동작을 담당합니다.

## 실행

```powershell
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

Streamlit 등록 화면은 고객 API를 통해 선택한 품종과 양식장 정보를 저장합니다. 별도 터미널에서 백엔드도 실행하세요.

```powershell
py -m pip install -r backend/backend/requirements.txt
py -m uvicorn backend.main:app --app-dir backend --reload --port 8000
```

백엔드는 `backend/backend/.env`의 DB 설정을 사용합니다. 프론트의 API 주소는 `NIFS_API_URL`로 설정하며 기본값은 `http://127.0.0.1:8000`입니다. 새 DB의 품종 초기 데이터는 [고객 API 안내](backend/CUSTOMER_API.md)에 따라 입력합니다.

## 화면 흐름

시작하기 → 양식장 등록 → 비회원으로 오늘의 위험정보 이용

선택 경로: 좌측 상단 로그인 → 로그인 화면 → 회원가입 → 가입 정보 입력 → 오늘의 위험정보

- Streamlit 버전은 비회원 양식장 등록, 회원가입, 로그인·로그아웃을 실제 고객 API로 처리합니다. 회원가입 시 같은 고객 ID와 양식장·품종 연결을 유지합니다. 비밀번호는 서버에서 해시 처리해 저장합니다.
- 세션 토큰은 현재 Streamlit 세션에 보관합니다. 브라우저 재접속 복원과 SMS 본인확인은 아직 연결하지 않았습니다.
- 전복 선택 시에만 육상·해상 버튼이 나타납니다. `customer_service.species`의 `전복(육상)` 또는 `전복(해상)` ID를 선택해 `farm_species`에 저장하며, 별도 전복 구분 컬럼은 사용하지 않습니다.
- 위험정보 화면의 수온, 주의 단계, 추이, 예측은 모두 고정 예시입니다.
- 위험정보 화면의 지역 좌표 조회는 실제 `public.sigungu_area_coordinates`를 사용합니다. 시·군·구 → 읍·면·리/지역을 선택하면 위도·경도와 좌표 유형을 표시합니다. 등록 지역이 기본 선택되며 다른 지역 조회는 양식장 등록 정보를 수정하지 않습니다.
- 오른쪽 위 ☰ 버튼으로 사이드 메뉴를 열고 닫을 수 있습니다. 양식장 정보 수정은 작동하며 대응 안내·보험 비교·상담은 준비 중 화면으로 연결됩니다.

## 수동 확인

1. 백엔드 실행 후 DB의 지역·품종 목록이 표시되는지 확인합니다. 연결이 실패하면 등록은 진행되지 않습니다.
2. 양식 정보를 모두 선택하고 등록하기를 누르면 가입 없이 위험정보 화면으로 이동합니다.
3. 좌측 상단 로그인 → 회원가입으로 이동합니다. 빈 이름, 미선택 생년월일, 잘못된 전화번호, 8자 미만 비밀번호는 가입을 막는지 확인합니다.
4. 정상 입력 후 가입완료를 누르면 위험정보 화면이 표시됩니다. 로그인 화면의 비회원으로 계속 이용도 같은 화면으로 돌아가며 양식장 설정을 유지합니다.
5. ☰ 메뉴 열기·닫기, 양식장 정보 수정 후 돌아오기, 준비 중 메뉴 이동을 확인합니다.
6. 모바일 폭에서도 메뉴와 입력 항목이 잘리지 않는지 확인합니다.
